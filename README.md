# ⭕ Tic-Tac-Toe

A responsive two-player Tic-Tac-Toe game built with vanilla JavaScript, HTML5, and CSS3 — no frameworks or libraries.

## 📌 About the Project

A classic two-player Tic-Tac-Toe game, playable in the browser on a single device. Built to practice DOM manipulation, game-state management, and win-condition logic without relying on any external libraries.

## 🛠️ Tech Stack

- **HTML5** — game board markup
- **CSS3** — responsive layout and styling
- **JavaScript (Vanilla)** — game state, turn handling, and DOM updates

## ✨ Features

- Two-player gameplay — X and O alternate turns on the same device
- Win detection across all 8 winning lines — 3 rows, 3 columns, 2 diagonals
- Draw detection when the board fills with no winner
- Restart/reset button to start a new round instantly, no page reload
- Responsive board that adapts cleanly from mobile to desktop
